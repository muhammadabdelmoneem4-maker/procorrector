# ProCorrector 2.0

برنامج للمعلمين لتسجيل **تعليقات صوتية قصيرة على الشاشة** أثناء تصحيح عمل الطالب.
يعمل على **ويندوز 10 و11** و**ماك (Apple Silicon وIntel)**، وواجهته بالعربية والإنجليزية.

## طريقة الاستخدام

1. افتح عمل الطالب على الشاشة (صورة، PDF، واجب، تلاوة…).
2. اكتب اسم الطالب في البرنامج (اختياري)، ثم اضغط **F8** من أي مكان على الجهاز.
3. تكلّم وأشر بالماوس على الأخطاء. يظهر شريط صغير أعلى الشاشة فيه المؤقت ومستوى الصوت، ولا يظهر هذا الشريط في التسجيل.
4. اضغط **F8** مرة أخرى (أو «حفظ» في الشريط). يُحفظ المقطع باسم الطالب ويظهر في قائمة البرنامج.
5. اسحب المقطع من القائمة إلى واتساب أو تيليجرام لإرساله مباشرة.

## المميزات

- زر واحد (F8) لبدء التسجيل وإيقافه من أي برنامج، ويمكن تغييره من الإعدادات.
- تسجيل الشاشة مع صوت المعلم بصيغة MP4 مناسبة للإرسال.
- تسمية المقاطع باسم الطالب تلقائيًا، وتعديل الاسم لاحقًا.
- قائمة بالتعليقات المسجلة مع صورة مصغّرة ومدة وحجم كل مقطع، وبحث بالاسم.
- سحب المقطع وإفلاته في واتساب أو تيليجرام أو البريد.
- زر «إلغاء» في شريط التسجيل للتخلص من تسجيل غير مرغوب.
- اختيار الميكروفون مع مؤشر لاختبار الصوت، واختيار الشاشة عند وجود أكثر من شاشة.
- جودة عالية (1080p) أو خفيفة للإرسال السريع (720p).
- مظهر فاتح وداكن، والبرنامج يبقى في شريط المهام (أو شريط القوائم على الماك) ليعمل F8 حتى لو أُغلقت النافذة.

## الحصول على ملفات التثبيت (عن طريق GitHub)

لا يمكن بناء نسخة الماك إلا على جهاز ماك، لذلك يقوم GitHub ببناء النسختين تلقائيًا ومجانًا.

### الطريقة الأولى: GitHub Desktop (الأسهل)

1. ثبّت [GitHub Desktop](https://desktop.github.com) وسجّل الدخول بحسابك.
2. فك ضغط مجلد المشروع، ثم من GitHub Desktop اختر **File → Add local repository** وحدد المجلد. سيعرض عليك إنشاء مستودع؛ وافق.
3. اضغط **Publish repository** (يمكنك تركه Private).
4. افتح المستودع على موقع GitHub، ثم تبويب **Actions**. ستجد عملية بناء اسمها «Build ProCorrector» بدأت تلقائيًا. انتظر حتى تصبح علامتها خضراء (حوالي 10 دقائق).
5. افتح العملية، وفي أسفل الصفحة تحت **Artifacts** نزّل:
   - `ProCorrector-Windows` ← بداخله ملف التثبيت ‎.exe
   - `ProCorrector-macOS` ← بداخله ملفان ‎.dmg: ‏`arm64` لأجهزة ماك M1/M2/M3/M4، و`x64` لأجهزة ماك Intel.

### إصدار نسخة رسمية بروابط ثابتة

لإنشاء صفحة **Release** بروابط تحميل دائمة تشاركها مع المعلمين: من GitHub افتح **Releases → Draft a new release**، واكتب في خانة الـ Tag مثلًا `v2.0.0`، ثم اضغط **Publish release**. سيبني GitHub الملفات ويضيفها للصفحة تلقائيًا.

## التثبيت عند المعلمين

### ويندوز

1. شغّل `ProCorrector-Setup-2.0.0.exe`.
2. إذا ظهرت شاشة زرقاء «Windows protected your PC»، اضغط **More info** ثم **Run anyway**. يظهر هذا التنبيه لأن البرنامج غير موقّع بشهادة مدفوعة.
3. أكمل التثبيت، وستظهر أيقونة البرنامج على سطح المكتب.

### ماك

1. افتح ملف ‎.dmg واسحب ProCorrector إلى مجلد **Applications**.
2. افتح البرنامج. سيمنعه الماك أول مرة لأنه غير موقّع من Apple. اذهب إلى **System Settings → Privacy & Security**، وانزل للأسفل واضغط **Open Anyway**.
3. عند أول تسجيل سيطلب الماك صلاحيتين: **الميكروفون** و**تسجيل الشاشة (Screen Recording)**. فعّل ProCorrector في الاثنين، ثم أعد تشغيل البرنامج.
4. على أغلب أجهزة الماك تكون أزرار F مخصصة للصوت والإضاءة، لذا اضغط **fn + F8**، أو غيّر زر التسجيل من الإعدادات إلى مجموعة مثل ‎⌥⌘R.

## للمطوّرين

```bash
npm install
npm start            # تشغيل البرنامج للتجربة
npm run dist:win     # بناء نسخة ويندوز (على ويندوز)
npm run dist:mac     # بناء نسخة ماك (على ماك)
```

- `main.js`: العملية الرئيسية (زر التسجيل العام، شريط المهام، حفظ المقاطع، شريط التسجيل العائم).
- `preload.js`: الجسر الآمن بين الواجهة والنظام.
- `src/`: الواجهة (`index.html`، `styles.css`، `app.js`) وشريط التسجيل (`indicator.html`).
- `.github/workflows/build.yml`: البناء التلقائي لويندوز وماك.

تُحفظ المقاطع افتراضيًا في مجلد `Videos/ProCorrector` (أو `Movies/ProCorrector` على الماك)، ويمكن تغييره من الإعدادات.
